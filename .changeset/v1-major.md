Release 1.0. There are no breaking API changes: every export, option, subpath and ace command from 0.x works unchanged, so upgrading is a version bump (see "Migrating to 1.0" in the docs).

- Node.js 24 or later is required (`engines.node: ">=24"`, unchanged).
- `@adonis-agora/media` accepts `@adonis-agora/authz`, `@adonis-agora/authkit-client`, `@adonis-agora/authkit-server` and `@adonis-agora/telescope` up to `<2.0.0` (lower bounds unchanged), so their 1.x lines work.
