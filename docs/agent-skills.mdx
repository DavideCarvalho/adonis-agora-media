`@adonis-agora/media` ships [Agent Skills](https://agentskills.io): short `SKILL.md` files that tell a
coding agent how to use the library, the patterns to follow and the mistakes to avoid. They live
inside the npm package (its `skills/` folder), so they always match the version you installed:
upgrade the package and the skills come with it.

## Skills in this package

| Skill | Package | Load it when |
| --- | --- | --- |
| `media-setup` | `@adonis-agora/media` | setting up media, choosing a store, wiring disks, running as a tenant of a control plane, answering a federated console, or fixing boot errors |
| `media-library-collections` | `@adonis-agora/media` | attaching files to entities, defining collections, generating thumbnails and conversions |
| `media-attachments-single-file` | `@adonis-agora/media` | a model "has a file" (avatar, logo) or another package delegates single-file uploads |
| `media-uploads-resumable` | `@adonis-agora/media` | uploading big files, resuming interrupted uploads (TUS, direct sessions) or writing an upload policy |
| `media-stores-delivery` | `@adonis-agora/media` | choosing or writing a store, wiring S3, serving media, signing URLs, or testing without disks |
| `media-dashboard-console` | `@adonis-agora/media-dashboard` | mounting or gating the media console, building admin routes over storage, or showing other apps' media |
| `media-react-uploads` | `@adonis-agora/media-react` | building upload UIs in React against the media server routes |

## Load them with TanStack Intent

[TanStack Intent](https://github.com/TanStack/intent) finds the skills in your installed packages
and tells your agent when to load them.

```bash
npm i -D @tanstack/intent    # pnpm add -D @tanstack/intent
npx intent install
```

The first `intent install` runs in a terminal: it asks which packages' skills to allow (saved as
`intent.skills` in your `package.json`) and writes a short skill-loading block into `AGENTS.md`
(or into the `CLAUDE.md`, `.cursorrules` or `.github/copilot-instructions.md` that already carries
it). To allow every Agora library without the prompt, for example in CI, add this to
`package.json` first:

```json
{
  "intent": { "skills": ["@adonis-agora/*"] }
}
```

Then your agent, or you, can list and load them:

```bash
npx intent list
npx intent load @adonis-agora/media#media-setup
```

`npx intent hooks install` adds hooks that remind Claude Code, Codex and Copilot to load a matching
skill before editing. Without Intent, point your agent at
`node_modules/@adonis-agora/media/skills/<skill>/SKILL.md`.

See [AI agent skills](/docs/agent-skills) for every Agora library that ships skills.
